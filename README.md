# Álgebra Superior con aplicaciones en R y GeoGebra

Edición estable del libro de **Jesús Gilberto Rodríguez Escobedo**.

Los capítulos 1 a 5 coordinan explicación matemática, código en R, figuras, laboratorios web y cuadernos completos para Google Colab. Los interactivos funcionan directamente en GitHub Pages, sin servidor. La versión incorpora índices temático, de figuras, de funciones de R, de símbolos y de laboratorios, además de referencias generales.
